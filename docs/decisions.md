Python libraries are used for:
* pil (Pillow): Processing and manipulating images. It is used to open, crop, resize, rotate, filter, and save many different image file formats.
* tkinter: Building Graphical User Interfaces (GUIs). It is Python's standard, built-in library for creating desktop windows, buttons, text boxes, and menus.
* os: Interacting with the operating system. It allows you to navigate folders, create or delete directories, manage file paths, and read environment variables.
